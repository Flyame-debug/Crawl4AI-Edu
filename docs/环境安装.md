## 成员C → 全体成员 环境安装教程

以下是我们项目所需环境的安装教程，请各成员按需安装。

---

## 一、PostgreSQL（数据库）

### Windows 安装

1. **下载安装包**
   - 官网：https://www.postgresql.org/download/windows/
   - 选择最新版本（psql (PostgreSQL) 18.4）

2. **安装步骤**
   - 运行安装程序，一路 Next
   - **设置密码**：记住你设置的密码（本项目使用 `123456`）
   - **端口**：保持默认 `5432`
   - **语言**：选择 `Chinese (Simplified)` 或默认

3. **验证安装**
   ```bash
   # 打开命令行
   psql -U postgres -h localhost -p 5432
   # 输入密码后进入数据库命令行
   ```

4. **创建数据库**
   ```sql
   CREATE DATABASE crawl_db;
   \q
   ```

## 二、Redis（缓存/消息队列）

### Windows 安装

1. **下载**
   - 官方推荐：https://github.com/microsoftarchive/redis/releases
   - 下载 `Redis-x64-xxx.msi`
    我的版本：redis-cli 5.0.14.1 (git:ec77f72d)

2. **安装步骤**
   - 运行安装程序
   - 勾选 `Add Redis to PATH`
   - 端口保持 `6379`

3. **启动 Redis**
   ```bash
   # 进入安装目录（如 D:\Redis）
   cd D:\Redis
   redis-server.exe
   ```

4. **验证安装**
   ```bash
   # 新开一个命令行窗口
   redis-cli ping
   # 应返回 PONG
   ```

## 三、MinIO（对象存储）

### Windows 安装

1. **下载 MinIO 服务器**
   ```powershell
   # 创建目录
   mkdir E:\minio
   cd E:\minio

   # 下载 minio.exe
   # 方法1：浏览器访问 https://dl.min.io/server/minio/release/windows-amd64/minio.exe
   # 方法2：PowerShell 下载
   Invoke-WebRequest -Uri "https://dl.min.io/server/minio/release/windows-amd64/minio.exe" -OutFile "minio.exe"
   ```
   我的版本：
   minio.exe version RELEASE.2025-09-07T16-13-09Z (commit-id=07c3a429bfed433e49018cb0f78a52145d4bedeb)
   Runtime: go1.24.6 windows/amd64
   License: GNU AGPLv3 - https://www.gnu.org/licenses/agpl-3.0.html
   Copyright: 2015-2025 MinIO, Inc.
   
2. **启动 MinIO**
   ```powershell
   # 创建数据目录
   mkdir data

   # 启动服务器
   .\minio.exe server .\data --console-address :9001
   ```

3. **访问控制台**
   - 地址：`http://127.0.0.1:9001`
   - 用户名：`minioadmin`
   - 密码：`minioadmin`

4. **创建 Bucket**
   - 登录后点击 `Buckets` → `Create Bucket`
   - 名称：`crawl4ai`
   - 点击 `Create Bucket`

## 四、Python 环境（项目虚拟环境）

### 创建虚拟环境

```bash
# 进入项目目录
cd E:\Crawl4AI

python -m venv venv

# 激活虚拟环境
.\venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt
```

详情见根目录requirements.txt

## 六、常见问题

| 问题 | 解决方法 |
|------|----------|
| 端口被占用 | 换端口：Redis `--port 6380`，MinIO `--console-address :9002` |
| PostgreSQL 连接失败 | 检查服务是否启动：`services.msc` → 找到 `postgresql` 服务启动 |
| Redis 不是内部命令 | 添加到 PATH 或 cd 到安装目录执行 |
| minio.exe 无法运行 | 下载文件可能损坏，重新下载 |
