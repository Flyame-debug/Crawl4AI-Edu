## 模块 A2-1：代码优化与稳定性增强

### 1. 优雅退出与信号处理

**功能说明**：API Worker 模式下支持通过 SIGINT（Ctrl+C）或 SIGTERM 信号实现优雅退出。

**开关控制**：
- 环境变量 `ENABLE_GRACEFUL_EXIT`：设为 `0` 禁用，默认 `1`（启用）
- 启动参数 `--no-graceful`：禁用优雅退出
- 默认状态：启用
- 优先级：`--no-graceful` > `ENABLE_GRACEFUL_EXIT` 环境变量

**实现细节**：
- 使用 `asyncio.Event` 作为退出标志
- 信号回调中设置事件（`signal.signal` 方式，兼容 Windows）
- 收到退出信号后，不再拉取新种子，等待当前批次中正在处理的种子完成（包括抓取、上传、上报结果）
- 退出前输出汇总统计：总处理种子数（成功/失败）、总页面数（成功/失败）、总图片数

**修改文件**：
- `sandbox/standalone_crawler/crawler.py`：添加 `_setup_signal_handlers()` 函数，在 `_run_api_worker` 中增加 `shutdown_event` 和 `graceful_enabled` 参数，修改轮询循环检查退出事件，添加汇总统计变量
- `sandbox/run_crawler.py`：新增 `--no-graceful` 参数，传递至 `crawl()`

**使用示例**：
```bash
# 默认启用优雅退出
python sandbox/run_crawler.py --worker

# 禁用优雅退出
python sandbox/run_crawler.py --worker --no-graceful

# 通过环境变量禁用
ENABLE_GRACEFUL_EXIT=0 python sandbox/run_crawler.py --worker
```

### 2. 图片上传并发数从后端配置读取

**功能说明**：图片下载/上传的并发数不再使用硬编码常量，改为从爬虫配置的 `concurrency` 字段读取，该字段同时控制页面抓取并发和图片处理并发。

**实现细节**：
- `_run_bfs_crawl()` 调用 `process_page()` 时传入 `image_concurrency=_max_concurrent`，其中 `_max_concurrent` 已从配置的 `concurrency` 字段解析
- `image_downloader/core.py` 的 `download_images()` 已支持 `concurrency` 参数（默认 5），无需额外修改
- 删除了对硬编码 `_DEFAULT_IMAGE_CONCURRENCY` 的依赖（仍保留作为 fallback 默认值）

**修改文件**：
- `sandbox/standalone_crawler/crawler.py`：在 `_run_bfs_crawl` 的 `process_page` 调用中添加 `image_concurrency=_max_concurrent`
- `sandbox/image_downloader/core.py`：无修改（已有 `concurrency` 参数）

**配置来源优先级**（与页面并发相同）：
1. 函数显式参数（`max_concurrent`）
2. 后端 API 配置 `/api/crawler/config/db/` 的 `concurrency` 字段（API 模式）
3. 本地 JSON 配置文件的 `concurrency` 字段（本地模式）
4. 内置默认值 5

### 3. 配置字段命名统一

**功能说明**：统一使用 `default_allowed_domains` 字段名，删除所有 `allowed_domains` 兼容代码。

**实现细节**：
- API 客户端 `get_config()` 返回后端原始响应，后端已新增 `default_allowed_domains` 字段
- `_run_api_worker()` 中从 API 配置读取 `default_allowed_domains`
- `_run_bfs_crawl()` 中从本地 JSON 配置读取 `default_allowed_domains`
- `crawler_config.json` 示例配置文件已使用 `default_allowed_domains` 字段名
- 删除了所有 `allowed_domains` / `default_allowed_domains` 的双字段兼容/回退逻辑

**修改文件**：
- `sandbox/standalone_crawler/crawler.py`：`_run_api_worker` 中 config key 从 `allowed_domains` 改为 `default_allowed_domains`
- `sandbox/standalone_crawler/api_client.py`：更新 `get_config()` 文档字符串中的字段名描述
- `sandbox/crawler_config.json`：已使用 `default_allowed_domains`（无需修改）
