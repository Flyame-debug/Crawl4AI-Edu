# A2-2-2 自动加密监测与质量检查报告

**日期**：2026-06-15
**成员**：成员 A
**任务**：实现自动反爬检测模块与爬取质量报告生成

---

## 任务概述

本次迭代实现了两个新模块：自动加密监测（anti_detect.py），用于在每次页面抓取后检测 WAF 拦截、验证码、JavaScript 挑战等反爬信号；质量检查报告（quality_report.py），在每次爬取任务结束时自动生成结构化 JSON 报告，统计成功率、内容长度、图片覆盖率及失败原因分类。

---

## 模块详情

### 1.1 自动加密监测（crawler/anti_detect.py）

实现了 `analyze_anti_crawl(url, html, status_code) -> dict` 函数，从三个维度检测反爬信号。状态码检测覆盖 403（禁止访问）、429（频率限制）、503（服务不可用），均标记 `suggest_render=True`。内容指纹检测在 HTML 中搜索 Cloudflare "Just a moment"、"Access Denied"、reCAPTCHA、hCaptcha、"验证码"等 15 种常见 WAF 提示模式。JavaScript 混淆检测扫描所有 `<script>` 标签内容，识别 `eval+unescape`、`_cf_chl`、`challenge-platform`、`fromCharCode`、`atob`、指纹采集、navigator 属性检测等 11 种反机器人脚本特征，并增加 50KB 阈值的大体积脚本启发式告警。

集成方式：在 `handlers.py` 的 `process_page` 函数中，抓取成功后立即检测 HTML 内容中的反爬指纹；抓取失败时从 FetchError 消息中解析 HTTP 状态码进行状态维度检测。检测结果通过 `logger.warning` 记录，并写入返回 dict 的 `anti_crawl` 字段。

### 1.2 质量检查报告（crawler/quality_report.py）

实现了 `generate_quality_report(task_stats, page_results, output_dir) -> str` 函数，对爬取任务的统计数据和逐页结果进行聚合分析，生成带时间戳的 JSON 报告文件并打印控制台摘要。计算指标包括成功率（success/total）、平均正文长度（从成功页面的 HTML 长度计算）、图片缺失率（成功页面中无图片的比例）。失败分析部分对每个失败 URL 的错误消息进行关键词分类，支持 Timeout、Anti-Crawl/Rate-Limit、Client Error (4xx)、Server Error (5xx)、DNS Resolution Failure、Connection Error、SSL/Certificate Error、HTML Parse Error 等八种类别，按类别统计数量并列出全部失败 URL。

输出 JSON 文件自动保存到爬取输出目录下的 `reports/` 子目录（如 `sandbox/data/reports/report_20260615.json` 或 `sandbox/preview_data/reports/report_20260615.json`），在 `_run_bfs_crawl` 结束时自动调用。

## 集成修改

### handlers.py
在 `process_page` 函数中引入 `analyze_anti_crawl`。抓取成功（HTTP 200）后对 HTML 内容执行反爬指纹检测，FetchError 分支通过正则提取状态码执行状态维度检测。检测结果写入结果 dict 的 `anti_crawl` 字段。

### crawler.py
在 `_run_bfs_crawl` 中新增 `_all_page_results` 列表，在每次 `stats.add_result()` 时同步累积逐页结果。`stats.stop()` 后自动调用 `generate_quality_report`，将报告保存到输出目录的 `reports/` 子目录。

## 测试结果

**anti_detect 模块**：三个测试用例全部通过。Cloudflare 挑战 HTML 被正确检测（3 个信号命中），403 无 HTML 被正确识别为反爬，干净页面返回负结果。
