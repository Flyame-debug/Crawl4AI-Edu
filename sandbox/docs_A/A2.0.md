## 模块 A2-1：代码优化与稳定性增强

### 1. 优雅退出与信号处理

**功能说明**：API Worker 模式下支持通过 SIGINT（Ctrl+C）或 SIGTERM 信号实现优雅退出。

**开关控制**：
- 环境变量 `ENABLE_GRACEFUL_EXIT`：设为 `0` 禁用，默认 `1`（启用）
- 启动参数 `--no-graceful`：禁用优雅退出
- 默认状态：启用
- 优先级：`--no-graceful` > `ENABLE_GRACEFUL_EXIT` 环境变量

**实现细节**：
- 使用 `asyncio.Event` 作为退出标志
- 信号回调中设置事件（`signal.signal` 方式，兼容 Windows）
- 收到退出信号后，不再拉取新种子，等待当前批次中正在处理的种子完成（包括抓取、上传、上报结果）
- 退出前输出汇总统计：总处理种子数（成功/失败）、总页面数（成功/失败）、总图片数

**修改文件**：
- `sandbox/standalone_crawler/crawler.py`：添加 `_setup_signal_handlers()` 函数，在 `_run_api_worker` 中增加 `shutdown_event` 和 `graceful_enabled` 参数，修改轮询循环检查退出事件，添加汇总统计变量
- `sandbox/run_crawler.py`：新增 `--no-graceful` 参数，传递至 `crawl()`

**使用示例**：
```bash
# 默认启用优雅退出
python sandbox/run_crawler.py --worker

# 禁用优雅退出
python sandbox/run_crawler.py --worker --no-graceful

# 通过环境变量禁用
ENABLE_GRACEFUL_EXIT=0 python sandbox/run_crawler.py --worker
```

### 2. 图片上传并发数从后端配置读取

**功能说明**：图片下载/上传的并发数不再使用硬编码常量，改为从爬虫配置的 `concurrency` 字段读取，该字段同时控制页面抓取并发和图片处理并发。

**实现细节**：
- `_run_bfs_crawl()` 调用 `process_page()` 时传入 `image_concurrency=_max_concurrent`，其中 `_max_concurrent` 已从配置的 `concurrency` 字段解析
- `image_downloader/core.py` 的 `download_images()` 已支持 `concurrency` 参数（默认 5），无需额外修改
- 删除了对硬编码 `_DEFAULT_IMAGE_CONCURRENCY` 的依赖（仍保留作为 fallback 默认值）

**修改文件**：
- `sandbox/standalone_crawler/crawler.py`：在 `_run_bfs_crawl` 的 `process_page` 调用中添加 `image_concurrency=_max_concurrent`
- `sandbox/image_downloader/core.py`：无修改（已有 `concurrency` 参数）

**配置来源优先级**（与页面并发相同）：
1. 函数显式参数（`max_concurrent`）
2. 后端 API 配置 `/api/crawler/config/db/` 的 `concurrency` 字段（API 模式）
3. 本地 JSON 配置文件的 `concurrency` 字段（本地模式）
4. 内置默认值 5

### 3. 配置字段命名统一

**功能说明**：统一使用 `default_allowed_domains` 字段名，删除所有 `allowed_domains` 兼容代码。

**实现细节**：
- API 客户端 `get_config()` 返回后端原始响应，后端已新增 `default_allowed_domains` 字段
- `_run_api_worker()` 中从 API 配置读取 `default_allowed_domains`
- `_run_bfs_crawl()` 中从本地 JSON 配置读取 `default_allowed_domains`
- `crawler_config.json` 示例配置文件已使用 `default_allowed_domains` 字段名
- 删除了所有 `allowed_domains` / `default_allowed_domains` 的双字段兼容/回退逻辑

**修改文件**：
- `sandbox/standalone_crawler/crawler.py`：`_run_api_worker` 中 config key 从 `allowed_domains` 改为 `default_allowed_domains`
- `sandbox/standalone_crawler/api_client.py`：更新 `get_config()` 文档字符串中的字段名描述
- `sandbox/crawler_config.json`：已使用 `default_allowed_domains`（无需修改）

## 模块 A2-2：实战爬取 – 华中科技大学教师全量抓取

### 概述

本模块完成了华中科技大学（HUST）教师数据的全量抓取，覆盖种子生成、试点验证、全量执行、数据索引与打包的完整流程。目标网站为 faculty.hust.edu.cn，共采集 12813 个 HTML 页面和 1323 张图片。

### 任务1：种子生成

编写了 `sandbox/seed_generators/generate_faculty_seeds.py`，通过分析 AJAX API 接口 `/system/resource/tsites/advancesearch.jsp`，逐页请求并解析返回的 JSON 数据。接口共返回 3350 名教师的个人主页 URL（格式为 `http://faculty.hust.edu.cn/{username}/zh_CN/index.htm`），总计 335 页（每页 10 条）。脚本设置 0.6 秒请求间隔并支持失败重试，最终生成无重复的种子文件 `sandbox/seeds/faculty_seeds.txt`（3350 条）。

### 任务2：试点爬取

取前 10 个种子 URL 进行了深度为 2 的试点抓取，验证了抓取策略的有效性。试点结果：1497 个页面中成功 1485 个（成功率 99.2%），下载图片 7184 张，无 IP 封禁或 429 响应。发现深度为 2 时页面扇出量过大（10 个种子产生约 1500 页），全量爬取调整深度为 1。详细报告见 `sandbox/logs/pilot_report.txt`。

### 任务3：配置文件

创建了目标高校专属配置 `sandbox/config/schools/hust_faculty.json`（allowed_domains、white_list_patterns、request_delay=2.0s、concurrency=2）。实现了 `sandbox/standalone_crawler/config_loader.py` 中的 `load_school_config(domain)` 函数，支持根据种子 URL 域名自动加载对应学校配置。

### 任务4：全量抓取

将 3350 个种子分为 5 批，每批约 670 个 URL，深度设置为 1，以 2 秒延迟和 2 并发执行。每批之间暂停 10 分钟以避免 IP 封禁。最终采集了 12813 个 HTML 页面（含教师主页及子栏目页如论文成果、科研项目等）和 1323 张图片，远超 3000 个 HTML 文件的验收标准。日志文件位于 `sandbox/logs/full_crawl_batch{1..5}.log`。

### 任务5：数据索引与打包

编写了 `sandbox/scripts/build_metadata.py`，通过读取爬虫运行时记录的 `sandbox/data/mapping.txt`（格式：URL|HTML路径|图片路径列表），重建了完整的 URL 到文件映射，生成 `sandbox/data/metadata.json`（12813 条记录，其中 12791 条包含至少一张图片）。最终将 `sandbox/data/` 目录打包为 `hust_faculty_data.tar.gz`（356MB，14141 个条目）。

### 修改的核心文件

- `sandbox/seed_generators/generate_faculty_seeds.py`：种子生成脚本（新建）
- `sandbox/standalone_crawler/handlers.py`：新增本地模式 HTML/图片持久化逻辑（`_save_page_locally` 函数及内嵌的图像下载与扩展名推导）
- `sandbox/standalone_crawler/crawler.py`：`crawl()` 和 `_run_bfs_crawl()` 新增 `seed_urls`、`output_dir` 参数，支持种子列表模式和自定义输出目录
- `sandbox/run_crawler.py`：新增 `--seed-list`、`--output-dir`、`--depth` 命令行参数
- `sandbox/standalone_crawler/config_loader.py`：学校配置加载模块（新建）
- `sandbox/config/schools/hust_faculty.json`：HUST 专属配置（新建）
- `sandbox/scripts/build_metadata.py`：数据索引生成脚本（新建）
