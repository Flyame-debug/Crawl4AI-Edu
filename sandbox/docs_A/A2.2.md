# 模块 A2-2：实战爬取 – 优化记录

## 子任务 1：华科加密修复 + 断点续爬

负责人：A2-2-1

### 目标

解决华中科技大学教师主页中"其他联系方式"等字段的 JS 加密问题（通过 Playwright 渲染重新抓取），并为爬虫增加断点续爬能力。

---

### 1.1 配置文件修改

**修改文件**：`sandbox/config/schools/hust_faculty.json`、`sandbox/standalone_crawler/config_loader.py`

在 HUST 高校配置中新增三个渲染相关字段：

```json
{
  "use_render": true,
  "render_for_depth": [0],
  "render_wait_time": 2
}
```

- `use_render`：总开关，控制是否启用 Playwright 渲染
- `render_for_depth`：数组，指定需要渲染的深度层级（仅 [0] 表示仅深度 0 即教师主页启用渲染）
- `render_wait_time`：页面加载后额外等待时间（秒），确保 JS 解密脚本完成执行

同时更新 `config_loader.py` 的 `_default_config()` 函数，使这些字段在所有配置中均有默认值（默认为关闭状态）。

### 1.2 Playwright 渲染重抓脚本

**新建文件**：`sandbox/scripts/rerender_hust_homepages.py`

该脚本使用 Playwright（headless Chromium）逐个访问所有深度为 0 的教师主页 URL，在浏览器环境中执行页面 JavaScript，获取解密后的完整 HTML 内容，并覆盖保存到 `sandbox/data/html/` 目录。

核心功能：从 metadata.json 读取 depth==0 的 URL 列表（约 3350 个），使用 Playwright 异步 API 启动 Chromium 浏览器，每个页面以 `networkidle` 策略加载，额外等待 `render_wait_time` 秒确保 JS 解密完成，获取渲染后 HTML 保存为 MD5 哈希文件名（覆盖原静态 HTML 文件）。支持断点续跑（通过 `sandbox/data/rerender_progress.txt` 记录已完成 URL），遵守配置中的 `request_delay`（2 秒）控制请求频率，日志同时输出到控制台和 `sandbox/logs/rerender.log`。

加密问题根因：HUST 教师主页使用 `tsitesencrypt.js` 对邮箱、电话等联系方式进行客户端加密。静态 HTTP 请求获取的 HTML 中这些字段为密文，需要浏览器执行 JavaScript 后才能显示为明文。Playwright 渲染模拟完整浏览器环境，触发解密逻辑。

### 1.3 断点续爬功能

**修改文件**：`sandbox/run_crawler.py`、`sandbox/standalone_crawler/crawler.py`

为爬虫核心增加通用断点续爬能力。

在 `run_crawler.py` 中新增 `--resume` 命令行参数，指定已爬 URL 记录文件路径（默认 `sandbox/data/crawled_urls.txt`）。在 `crawler.py` 的 `crawl()` 和 `_run_bfs_crawl()` 函数中新增 `resume_path` 参数。核心实现为：启动时从记录文件加载已爬 URL 到内存集合（set），初始种子列表中过滤掉已爬 URL，_worker 函数中检查 URL 是否在已爬集合中从而跳过，成功处理页面后通过异步队列和后台 writer 任务追加 URL 到记录文件（使用 asyncio.Queue + 独立 writer 协程确保并发环境下的线程安全）。

### 1.4 测试与交付

**加密解密验证**：通过对比 100 个已渲染页面的随机样本，手机号解密率达到 100%（所有页面均含明文手机号），邮箱可见率为 61%（并非所有教师公开邮箱）。以教师 LongQie 为例，渲染前静态 HTML 中邮箱字段为加密状态（含 `tsitesencrypt` 标记），渲染后可在页面文本中读取到明文邮箱 `qie@hust.edu.cn`，保存的 HTML 文件也包含解密后的内容。

**断点续爬测试**：首次运行处理 1 个 URL 并记录到 `crawled_urls.txt`，第二次运行时正确识别已爬 URL 并跳过，处理页面数为 0，断点续爬逻辑验证通过。

**全量渲染进度**：metadata.json 共包含 3771 个深度 0 URL（含中英文教师主页），Playwright 渲染速度约 12 页/分钟（每页等待 `networkidle` 事件 + 2 秒额外延迟），预计全量完成需约 5 小时。渲染支持断点续跑，进度记录在 `sandbox/data/rerender_progress.txt`，中断后重新运行脚本可自动跳过已完成页面。
