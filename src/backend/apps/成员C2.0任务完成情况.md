- `POST /api/auth/login/` - 用户登录

- `GET /api/stats/` - 仪表盘统计
- `GET /api/crawler/status/` - 爬虫状态
- `GET /api/logs/` - 日志查询
- `GET /api/health/` - 健康检查
- `POST /api/auth/send-code/` - 发送验证码

#### 成员A专用接口
- `GET /api/crawler/config/db/` - 获取爬虫配置
- `GET /api/seeds/pending/` - 获取待爬种子
- `POST /api/seeds/status/` - 更新种子状态
- `POST /api/images/upload/` - 图片上传（MinIO）
- `POST /api/pagesnapshot/` - 保存网页快照（核心）
- `POST /api/crawl/start/` - 启动爬虫任务
- `POST /api/tasks/{id}/result/` - 上报任务结果
- `POST /api/ai/generate-rules/` - **P2新增** AI生成采集规则

#### 成员B专用接口
- `POST /api/ai/clean-status/` - **P2新增** AI清洗结果上报

#### 成员D专用接口
- `GET /api/templates/` - 模板列表（支持分类筛选）
- `POST /api/templates/create/` - 创建模板
- `GET /api/templates/{id}/` - 模板详情
- `PUT /api/templates/{id}/update/` - 更新模板
- `DELETE /api/templates/{id}/delete/` - 删除模板
- `GET /api/templates/history/` - **P1新增** 历史模板
- `POST /api/tasks/start/` - 启动采集任务（核心改造）
- `POST /api/tasks/{id}/pause/` - 暂停任务
- `POST /api/tasks/{id}/stop/` - 停止任务
- `DELETE /api/tasks/{id}/delete/` - 删除任务
- `GET /api/tasks/` - 任务列表
- `GET /api/tasks/{id}/detail/` - 任务详情
- `GET /api/tasks/{id}/progress/` - 任务进度轮询
- `GET /api/tasks/{id}/preview/` - 采集数据预览
- `GET /api/tasks/{id}/download/` - 结果下载（JSON/CSV）
